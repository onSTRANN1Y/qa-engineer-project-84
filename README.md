# Проект: Тестирование интернет-магазина

## Знакомство с приложением
В рамках данного проекта проводится комплексное тестирование веб-приложения — учебного интернет-магазина по продаже товаров. Основная цель — выявление дефектов верстки, логики работы интерфейса (UI), фильтрации, локализации (i18n) и клиент-серверного взаимодействия (API).

## Ссылки
* **Тестируемое приложение:** [Hexlet Store](https://products-store-v2.hexlet.app/)

## Задачи
* **Ознакомление с функционалом:** Изучение возможностей приложения, структуры каталога и пользовательских сценариев.
* **Составление тестовой документации:** Написание чеклистов, тест-кейсов и баг-репортов.
* **Функциональное тестирование:** Проверка работы корзины, поиска, фильтрации и оформления заказа.
* **Тестирование локализации и UI:** Проверка корректности смены языков и верстки элементов.
* **Инспектирование сетевых запросов:** Анализ работы API с помощью DevTools.
