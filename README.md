# Проект: Тестирование интернет-магазина (Hexlet Store)

## Знакомство с приложением
В этом проекте предстоит провести тестирование веб-приложения — небольшого интернет-магазина по продаже товаров. В рамках работы тестируются две версии приложения для проверки пользовательских сценариев, верстки, локализации (i18n) и клиент-серверного взаимодействия (API).

## Ссылки (Тестируемые приложения)
* **Первая версия (v1):** [products-store.hexlet.app](https://products-store.hexlet.app/) 
* **Вторая версия (v2):** [products-store-v2.hexlet.app](https://products-store-v2.hexlet.app/) 

## Задачи
* **Ознакомление с функционалом:** Изучение приложения, его возможностей и структуры каталога на обеих версиях.
* **Составление тестовой документации:** Написание тест-кейсов и баг-репортов.
* **Функциональное тестирование:** Проверка работы корзины, поиска, фильтрации и оформления заказа.
* **Тестирование локализации и UI:** Проверка корректности перевода элементов интерфейса и целостности верстки.
* **Инспектирование сетевых запросов:** Анализ работы API и отслеживание статусов запросов с помощью DevTools.
